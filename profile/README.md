# Buburtech Team

Welcome to the GitHub organization for the **Buburtech Team**.

This organization is used to develop and maintain internal software solutions that support the team's audit activities and operational processes.

## About

The projects hosted within this organization are developed exclusively for internal business use and are not intended for public distribution.

At this time, all repositories are private and are accessible only to authorized members of the Internal IT Audit Team and approved collaborators.

## Services

Buburtech is split into services named after bubur ayam toppings. Repository names drop the `tech` suffix.

| Repository | Purpose |
|------------|---------|
| `cakwe` | Users, access and HR personnel data |
| `suwir` | Knowledge Base (controls, risks, ITGC, releases) |
| `telur` | Engagement |
| `kerupuk` | Documents and evidence |
| `bawang` | Notifications and realtime |
| `kuah` | Gateway |
| `tongcai` | Client and engagement registry (read-only from the external portal) |
| `kecap` | Tenant and platform |
| `seledri` | Audit trail |
| `mangkok` | Frontend monorepo |
| `sendok` | Shared .NET libraries |
| `gerobak` | Infrastructure and deployment |

Work is tracked in the organization project [Buburtech](https://github.com/orgs/buburtech/projects/5). Issue and pull request templates come from this repository.

## Repository Access

If you are looking for a repository that you believe you should have access to, please contact the organization administrator or the project owner.
